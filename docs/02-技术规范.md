## 架构模式：MVVM

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│    Model     │     │  ViewModel   │     │    View      │
│  数据模型    │ ◀── │  业务逻辑    │ ◀── │   UI 界面    │
│  SwiftData   │     │  @Published  │     │  SwiftUI     │
└──────────────┘     └──────────────┘     └──────────────┘
```

- **Model**：纯数据结构，SwiftData 模型类
- **ViewModel**：`@Observable` 类，处理业务逻辑，暴露 `@Published` 属性驱动 UI
- **View**：SwiftUI 视图，只负责展示和用户交互，不写业务逻辑

## 核心框架（全部 Apple 原生）

| 框架 | 用途 | 用到哪些功能 |
|------|------|-------------|
| PDFKit | PDF 操作 | 合并、拆分、缩略图预览 |
| CoreImage | 图片处理 | 压缩、格式转换、滤镜 |
| ImageIO | 图片读写 | 多格式导入导出（JPG/PNG/WebP/HEIC 等）|
| AVFoundation | 视频处理 | 视频压缩、格式转换 |
| Vision | 人像分割 | 证件照抠图（VNGeneratePersonSegmentationRequest）|
| CoreImage | 图像增强 | 提亮、美颜、锐化滤镜链 |
| UniformTypeIdentifiers | 文件类型识别 | 判断文件格式、UTI 管理 |
| SwiftData | 数据存储 | 历史记录持久化 |
| AppKit | Mac 底层能力 | 文件选择、拖拽、右键菜单 |
| Combine | 响应式编程 | 进度回调、状态管理 |

## 零第三方依赖策略

**为什么不用第三方库？**
1. 减少外部依赖的安全风险
2. 避免依赖库不更新导致的兼容问题
3. 降低项目复杂度，方便学习和维护
4. Apple 原生框架已覆盖所有 MVP 需求

**特别说明**：
- 证件照抠图：Vision 框架 `VNGeneratePersonSegmentationRequest` 是 Apple 在 macOS 14+ 内置的人像分割 API，可生成人像遮罩，配合 CoreImage 实现背景替换，无需 AI 模型
- Word 转 PDF：macOS 系统内置 `NSAttributedString` 和 `NSTextView` 可读取 .docx，配合 PDFKit 生成 PDF
- 视频压缩：AVFoundation 的 `AVAssetWriter` 完全满足需求

## 代码规范

### 命名规范
- 文件名：大驼峰（PascalCase），如 `FileRenameService.swift`
- 变量/函数：小驼峰（camelCase），如 `selectedFiles`
- 类/结构体/枚举：大驼峰，如 `ImageCompressor`
- 常量：小驼峰，如 `defaultQuality`

### 文件组织
- 按功能模块分包，不是按文件类型
- 每个 View 对应一个 ViewModel（如需要）
- Service 层统一放在 `Shared/Services/`

### 注释规范
- 复杂逻辑用中文注释解释 WHY，不是 WHAT
- 公开接口用 `///` 文档注释
- 每个 Service 的公开方法写简短说明

## 项目配置

### Xcode 项目结构
```
RuiTuOfficeMaster.xcodeproj
├── Shared/          (蓝色文件夹，代码共享)
│   ├── Models/
│   ├── ViewModels/
│   ├── Views/
│   ├── Services/
│   └── Utils/
├── macOS/           (macOS Target)
│   ├── App/
│   ├── Views/
│   └── Resources/
│       └── Assets.xcassets
```

### Target 配置
- macOS Deployment Target: 14.0
- Swift Language Version: Swift 6.0
- App Sandbox: 开启（App Store 要求）
- Hardened Runtime: 开启（macOS 签名要求）
