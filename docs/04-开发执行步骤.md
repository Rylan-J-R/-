# 04 - 开发执行步骤

## 开发总览

| Sprint | 周期 | 目标 | 关键产出 |

## Sprint 2：批量改名 + 图片压缩

### 学习目标
- 文件操作（NSOpenPanel、FileManager）

- [ ] `ImageCompressionViewModel.swift` — 状态管理
- [ ] `ImageCompressionView.swift` — 主界面

## Swift 学习路径（参考）

```
第1周: Swift 基础       第2周: SwiftUI 入门     第3周: 进阶
┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│ 变量与常量   │      │ View 协议    │      │ @Observable  │
│ 基本数据类型 │      │ Text/Image   │      │ @State       │
│ 数组与字典   │ ───▶ │ Button/VStack│ ───▶ │ @Binding     │
│ 函数与方法   │      │ HStack/ZStack│      │ @Environment │
│ 结构体与类   │      │ List/ForEach │      │ Combine      │
│ if/guard/for │      │ Navigation   │      │ SwiftData    │
└──────────────┘      └──────────────┘      └──────────────┘
```
