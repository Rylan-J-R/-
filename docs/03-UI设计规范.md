# 03 - UI设计规范

## 设计风格

**简约扁平化现代商务风** — 干净清爽、条理清晰、通俗易懂。

核心原则：
- 少即是多：去除一切不必要的装饰
- 一目了然：信息层级分明，用户 3 秒内找到需要的功能
- 老少皆宜：图标+文字双重识别，操作步骤不超过 3 步

## 组件规范

### 功能卡片（FeatureCard）

```
┌──────────────────────┐
│                      │
│       🖼 图标        │
│      （32pt）        │
│                      │
│    功能标题（16pt）   │
│   简要描述（12pt）    │
│                      │
└──────────────────────┘
```

- 尺寸：160x140 pt
- 圆角：12 pt
- 背景：卡片色
- 阴影：`y: 2, blur: 8, opacity: 0.08`
- hover 态：上移 2pt + 阴影加深 + 主色边框

### 侧边栏（Sidebar）

- 宽度：220 pt
- 导航项高度：36 pt
- 图标尺寸：18 pt，使用 SF Symbols
- 选中态：左侧 3pt 主色竖条 + 背景变为主色浅
- 分组标题：12pt，大写，灰色，字间距 1pt

### 按钮

- 圆角：8 pt
- 主按钮：主色背景 + 白色文字，hover 时加深 5%
- 次按钮：主色描边 + 主色文字，hover 时填充浅色背景
- 高度：标准 36pt，小号 28pt
- padding：水平 16pt，垂直 8pt

### 进度条（ProgressBar）

```
┌──────────────────────────────────┐
│ ████████████░░░░░░░░  45%       │
│ 处理中: 图片_003.jpg            │
└──────────────────────────────────┘
```

- 高度：6 pt
- 圆角：3 pt
- 已完成部分：主色
- 剩余部分：灰色（`#E5E5EA`）
- 右侧显示百分比 + 下方显示当前处理文件名

```
┌──────┬──────────────────────────────────┐
│      │                                  │
│ 侧边 │         主内容区                 │
```

### 间距系统（8pt 网格）

| 间距 | 数值 | 用途 |
|------|------|------|
| xs | 4pt | 紧密元素间 |
| sm | 8pt | 相关元素间 |
| md | 16pt | 标准间距（最常用）|
| lg | 24pt | 区块间距 |
| xl | 32pt | 大区块分隔 |
| 2xl | 48pt | 页面顶部/底部留白 |

### 内容区
- 最大宽度：900pt，居中显示
- 卡片间距：16pt
- 内容区 padding：水平 32pt，垂直 24pt

## 深浅模式切换

- 位置：侧边栏底部或设置页面
- 默认：跟随系统
- 切换方式：分段控制器（浅色 / 深色 / 自动）
- 切换动画：0.3 秒渐变过渡
