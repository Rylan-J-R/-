# -
锐途办公大师是基于 Python 开发的图形化桌面工具，面向高校学生，一站式解决学习、竞赛场景下各类文件处理难题。软件采用简洁直观的界面，无需掌握命令行，上手门槛低。  内置八大核心工具：批量文件改名、图片压缩与尺寸调整、多格式图片互转、证件照生成换底色、PDF 合并拆分加密、视频压缩、音视频格式转换、图片 OCR 文字提取。整理课程作业、科创竞赛材料时，大量重复繁琐的文件操作可以一键完成，省去手动逐个处理的时间。  本项目为个人学习研发作品，仅用于技术演示，禁止商用。项目使用 Python3.10 及以上版本开发，依赖 Pillow、pypdf、opencv-python 等开源库。欢迎 Star、Fork，也欢迎提交 Issue 反馈 bug 与新功能建议。
